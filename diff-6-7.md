# Pong: від `pong-6` до `pong-7` — «The Collision Update»

## 1. Загальний опис завдання

У `pong-6` м'яч має метод `collides`, але ніхто його не використовує: м'яч пролітає крізь ракетки й вилітає за екран.

У `pong-7` м'яч нарешті **відбивається**:

- від **ракеток** — змінює горизонтальний напрямок, щоразу пришвидшується на 3% і отримує випадковий вертикальний кут;
- від **верхньої та нижньої стін** — змінює вертикальний напрямок.

Також даємо м'ячу нормальну швидку **горизонтальну** стартову швидкість, щоб він летів до гравця, а не переважно вгору-вниз.

## 2. Кроки від `pong-6` до `pong-7`

### Крок 1. Оновіть коментар-заголовок

```lua
    pong-7
    "The Collision Update"
```

### Крок 2. Дайте м'ячу швидший горизонтальний старт

У `Ball.lua`, всередині `Ball:init`, замініть рядок із `self.dx`:

```lua
    self.dx = math.random(2) == 1 and math.random(-80, -100) or math.random(80, 100)
```

> 50% шанс полетіти ліворуч зі швидкістю приблизно 80–100 px/с, 50% — праворуч. (У стандартному Lua слід писати `math.random(-100, -80)` — спершу менше число. LuaJIT у LÖVE приймає порядок, використаний в оригінальному репозиторії.)
>
> Змінюється лише `init` — `Ball:reset()` досі використовує старий `math.random(-50, 50)`.

### Крок 3. Відкрийте блок зіткнень у `love.update(dt)`

На **самому початку** `love.update(dt)`, перед кодом керування ракетками, відкрийте блок, що працює лише під час гри:

```lua
    if gameState == 'play' then
        -- (сюди йдуть кроки 4–6)
    end
```

### Крок 4. Відбиття від гравця 1 (ліва ракетка)

Усередині цього блоку:

```lua
        if ball:collides(player1) then
            ball.dx = -ball.dx * 1.03
            ball.x = player1.x + 5

            if ball.dy < 0 then
                ball.dy = -math.random(10, 150)
            else
                ball.dy = math.random(10, 150)
            end
        end
```

> - `-ball.dx` змінює напрямок; `* 1.03` робить м'яч на 3% швидшим після кожного удару, тож розіграші стають складнішими.
> - `ball.x = player1.x + 5` виштовхує м'яч одразу за межі ракетки (ширина ракетки — 5). Без цього м'яч міг би ще перетинатися з ракеткою в наступному кадрі, знову «зіткнутися» і застрягнути.
> - Вертикальна швидкість стає випадковою, але зберігає той самий напрямок угору/вниз.

### Крок 5. Відбиття від гравця 2 (права ракетка)

Та сама ідея, але м'яч виштовхується **ліворуч** від ракетки (ширина м'яча — 4):

```lua
        if ball:collides(player2) then
            ball.dx = -ball.dx * 1.03
            ball.x = player2.x - 4

            if ball.dy < 0 then
                ball.dy = -math.random(10, 150)
            else
                ball.dy = math.random(10, 150)
            end
        end
```

### Крок 6. Відбиття від верхньої та нижньої стін

Усе ще всередині блоку `if gameState == 'play'`:

```lua
        -- верхня стіна
        if ball.y <= 0 then
            ball.y = 0
            ball.dy = -ball.dy
        end

        -- нижня стіна (-4 — висота м'яча)
        if ball.y >= VIRTUAL_HEIGHT - 4 then
            ball.y = VIRTUAL_HEIGHT - 4
            ball.dy = -ball.dy
        end
```

### Крок 7. (Необов'язково) Колір FPS у записі 0–255

У `displayFPS()` оригінальний репозиторій записує зелений так:

```lua
    love.graphics.setColor(0, 255/255, 0, 255/255)
```

Це точнісінько той самий колір, що й `(0, 1, 0, 1)`, — просто записаний у стилі «0–255, поділене на 255», як і колір фону.

### Крок 8. Запустіть і перевірте

Запустіть `love .` і натисніть **Enter**. М'яч летить ліворуч або праворуч, відбивається від верхньої й нижньої стін і від ракеток, пришвидшуючись після кожного удару. Якщо він проскакує повз ракетку, то досі вилітає за екран — нарахування очок буде на наступному кроці.
