# Pong: від `pong-0` до `pong-1` — «The Low-Res Update»

## 1. Загальний опис завдання

У `pong-0` гра відкриває вікно 1280×720 і виводить **«Hello Pong!»** стандартним шрифтом LÖVE у повній роздільній здатності вікна.

У `pong-1` ми надаємо грі ретро-вигляду: малюємо все в значно меншій **віртуальній роздільній здатності** (432×243) і збільшуємо до розміру вікна. Для цього підключаємо сторонню бібліотеку **push**. Також ми:

- вмикаємо фільтрацію «nearest-neighbor» (за найближчим сусідом), щоб збільшені пікселі залишалися чіткими, а не розмитими;
- робимо вікно таким, що змінює розмір (push правильно масштабує зображення);
- дозволяємо гравцю вийти з гри клавішею **Escape**.

| Файл | Що відбувається |
|---|---|
| `main.lua` | Змінюється |

## 2. Кроки від `pong-0` до `pong-1`

### Крок 1. Додайте бібліотеку push

Скопіюйте [`assets/push.lua`](assets/push.lua) у папку проєкту, поруч із `main.lua`. Вона відповідає за малювання у віртуальній роздільній здатності та масштабування до реального вікна.

### Крок 2. Оновіть коментар-заголовок

```lua
    pong-1
    "The Low-Res Update"
```

### Крок 3. Підключіть push

На початку `main.lua`, перед константами вікна:

```lua
push = require 'push'
```

> `require 'push'` завантажує `push.lua` з тієї ж папки (розширення `.lua` писати не треба).

### Крок 4. Додайте константи віртуальної роздільної здатності

Під `WINDOW_WIDTH` і `WINDOW_HEIGHT`:

```lua
VIRTUAL_WIDTH = 432
VIRTUAL_HEIGHT = 243
```

> 432×243 зберігає те саме співвідношення 16:9, що й 1280×720, і близьке до роздільної здатності старих консолей на кшталт NES.

### Крок 5. Увімкніть фільтрацію за найближчим сусідом

Перший рядок усередині `love.load()`:

```lua
    love.graphics.setDefaultFilter('nearest', 'nearest')
```

> Без цього LÖVE згладжує (розмиває) графіку під час масштабування. Спробуйте потім прибрати цей рядок і порівняйте.

### Крок 6. Дозвольте змінювати розмір вікна

У параметрах `love.window.setMode` замініть `resizable = false` на:

```lua
        resizable = true,
```

### Крок 7. Налаштуйте push

У кінці `love.load()`:

```lua
    push.setupScreen(VIRTUAL_WIDTH, VIRTUAL_HEIGHT, { upscale = 'normal' })
```

### Крок 8. Вихід клавішею Escape

Додайте нову функцію після `love.load()`. LÖVE викликає її щоразу, коли натиснуто клавішу:

```lua
function love.keypressed(key)
    if key == 'escape' then
        love.event.quit()
    end
end
```

### Крок 9. Малюйте через push

Перепишіть `love.draw()` так, щоб усе малювалося між `push.start()` і `push.finish()`, а текст розміщувався за **віртуальним** розміром замість розміру вікна:

```lua
function love.draw()
    push.start()

    love.graphics.printf('Hello Pong!', 0, VIRTUAL_HEIGHT / 2 - 6, VIRTUAL_WIDTH, 'center')

    push.finish()
end
```

> Відтепер усі координати в грі задаються у віртуальних пікселях (0–432 по горизонталі, 0–243 по вертикалі).

### Крок 10. Запустіть і перевірте

Запустіть `love .`. Текст тепер великий і піксельний — той самий стандартний шрифт, але намальований маленьким і збільшений. Змініть розмір вікна — зображення масштабується. Натисніть **Escape**, щоб вийти.
