# Pong: від `pong-10` до `pong-11` — «The Audio Update»

## 1. Загальний опис завдання

`pong-10` — це вже повноцінна гра, але беззвучна.

У `pong-11` додаємо **звукові ефекти**:

- «біп», коли м'яч б'ється об **ракетку**;
- інший звук, коли він б'ється об **верхню чи нижню стіну**;
- звук, коли хтось **здобуває очко**.

Звукові файли — готові ресурси, ми їх лише підключаємо. Також встановлюємо справжню переможну кількість очок — **10**.

## 2. Кроки від `pong-10` до `pong-11`

### Крок 1. Додайте звукові файли

Створіть у проєкті папку `sounds` і скопіюйте в неї три `.wav`-файли з [`assets/sounds/`](assets/sounds/):

```
sounds/
  paddle_hit.wav
  score.wav
  wall_hit.wav
```

### Крок 2. Оновіть коментар-заголовок

```lua
    pong-11
    "The Audio Update"
```

### Крок 3. Завантажте звуки в `love.load()`

Після створення шрифтів:

```lua
    sounds = {
        ['paddle_hit'] = love.audio.newSource('sounds/paddle_hit.wav', 'static'),
        ['score'] = love.audio.newSource('sounds/score.wav', 'static'),
        ['wall_hit'] = love.audio.newSource('sounds/wall_hit.wav', 'static')
    }
```

> - `sounds` — це **таблиця** Lua, яку використовуємо як словник: шукаємо кожен звук за назвою.
> - `'static'` завантажує весь звук у пам'ять один раз — найкраще для коротких ефектів, що відтворюються часто. (Для довгої музики використовують `'stream'`.)

### Крок 4. Відтворюйте звук при ударі об ракетку

У `love.update(dt)`, у кінці **кожного** блоку зіткнення з ракеткою (`if ball:collides(player1)` та `if ball:collides(player2)`), додайте:

```lua
            sounds['paddle_hit']:play()
```

### Крок 5. Відтворюйте звук при ударі об стіну

В **обох** перевірках стін (верхньої й нижньої), після `ball.dy = -ball.dy`:

```lua
            sounds['wall_hit']:play()
```

### Крок 6. Відтворюйте звук, коли хтось здобуває очко

В **обох** перевірках країв, одразу після збільшення рахунку (`player2Score = player2Score + 1` та `player1Score = player1Score + 1`):

```lua
            sounds['score']:play()
```

### Крок 7. Встановіть переможну кількість очок — 10

В обох перевірках країв замініть умову `== 2` на:

```lua
            if player2Score == 10 then
```

```lua
            if player1Score == 10 then
```

### Крок 8. (Необов'язково) Колір FPS

Оригінальний репозиторій знову записує зелений як `love.graphics.setColor(0, 255/255, 0, 255/255)` — це той самий колір, що й раніше.

### Крок 9. Запустіть і перевірте

Запустіть `love .` і грайте з увімкненим звуком. Ви маєте чути різні звуки для ударів об ракетку, відбиття від стін і здобутих очок. Гра тепер закінчується на 10 очках.
