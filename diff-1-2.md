# Pong: від `pong-1` до `pong-2` — «The Rectangle Update»

## 1. Загальний опис завдання

У `pong-1` гра лише показує текст **«Hello Pong!»** посередині екрана з низькою (віртуальною 432×243) роздільною здатністю.

У `pong-2` ми починаємо малювати справжні ігрові об'єкти. Мета кроку — щоб екран *виглядав* як Pong, хоча нічого ще не рухається:

- використати піксельний ретрошрифт замість стандартного шрифту LÖVE;
- зафарбувати фон темним сіро-синім кольором, як у деяких версіях оригінального Pong;
- перемістити вітальний текст угору екрана;
- намалювати дві ракетки (ліву й праву) та м'яч у вигляді простих білих прямокутників.

### Файли

| Файл | Що відбувається |
|---|---|
| `main.lua` | Змінюється (уся робота цього кроку) |
| [`push.lua`](assets/push.lua) | Стороння бібліотека, без змін — залишається з `pong-1` |
| [`font.ttf`](assets/font.ttf) | **Новий.** Сторонній файл шрифту — просто скопіюйте в папку проєкту, не створюйте його |

## 2. Кроки від `pong-1` до `pong-2`

### Крок 1. Додайте файл шрифту

Скопіюйте [`assets/font.ttf`](assets/font.ttf) у папку проєкту, поруч із `main.lua` і `push.lua`. Це готовий піксельний шрифт; ми його лише підключаємо.

### Крок 2. Оновіть коментар-заголовок

На початку `main.lua` змініть назву версії:

```lua
    pong-2
    "The Rectangle Update"
```

### Крок 3. Завантажте ретрошрифт у `love.load()`

Одразу після `love.graphics.setDefaultFilter('nearest', 'nearest')` створіть об'єкт шрифту розміром 8 і зробіть його активним:

```lua
    -- шрифт у ретростилі для будь-якого тексту
    smallFont = love.graphics.newFont('font.ttf', 8)

    -- робимо smallFont активним шрифтом LÖVE2D
    love.graphics.setFont(smallFont)
```

> Чому розмір 8? Ми малюємо в дуже малій віртуальній роздільній здатності, тож маленький шрифт після збільшення перетворюється на чіткі «великі» пікселі. Фільтр `'nearest'` зберігає його різкість.

### Крок 4. Очищуйте екран кольором фону

У `love.draw()`, одразу після `push.start()`, заповніть увесь екран темним кольором:

```lua
    love.graphics.clear(40/255, 45/255, 52/255, 255/255)
```

> LÖVE 11+ очікує кольори в діапазоні 0–1, тому ділимо звичні значення 0–255 на 255.

### Крок 5. Перемістіть вітальний текст угору

Замініть старий `printf` по центру на такий, що розміщує текст на 20 пікселів нижче верхнього краю:

```lua
    love.graphics.printf('Hello Pong!', 0, 20, VIRTUAL_WIDTH, 'center')
```

### Крок 6. Намалюйте ліву ракетку

Ракетки — це просто зафарбовані прямокутники шириною 5 px і висотою 20 px:

```lua
    -- перша ракетка (ліворуч)
    love.graphics.rectangle('fill', 10, 30, 5, 20)
```

Аргументи: `режим, x, y, ширина, висота`.

### Крок 7. Намалюйте праву ракетку

Розмістіть її біля правого краю, ближче до низу:

```lua
    -- друга ракетка (праворуч)
    love.graphics.rectangle('fill', VIRTUAL_WIDTH - 10, VIRTUAL_HEIGHT - 50, 5, 20)
```

### Крок 8. Намалюйте м'яч

Квадрат 4×4 по центру. Віднімаємо половину розміру (2), щоб посередині екрана опинився *центр* м'яча, а не його лівий верхній кут:

```lua
    -- м'яч (по центру)
    love.graphics.rectangle('fill', VIRTUAL_WIDTH / 2 - 2, VIRTUAL_HEIGHT / 2 - 2, 4, 4)
```

Усе малювання має залишатися між `push.start()` і `push.finish()`.

### Крок 9. Запустіть і перевірте

Запустіть проєкт (`love .`). Ви маєте побачити темний фон, «Hello Pong!» угорі піксельним шрифтом, ракетку зліва вгорі, ракетку справа внизу й маленький м'яч по центру. Нічого ще не рухається — це буде на наступному кроці.

## Готовий `love.draw()` для звірки

```lua
function love.draw()
    push.start()

    love.graphics.clear(40/255, 45/255, 52/255, 255/255)

    love.graphics.printf('Hello Pong!', 0, 20, VIRTUAL_WIDTH, 'center')

    love.graphics.rectangle('fill', 10, 30, 5, 20)
    love.graphics.rectangle('fill', VIRTUAL_WIDTH - 10, VIRTUAL_HEIGHT - 50, 5, 20)
    love.graphics.rectangle('fill', VIRTUAL_WIDTH / 2 - 2, VIRTUAL_HEIGHT / 2 - 2, 4, 4)

    push.finish()
end
```
